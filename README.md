# data-fair.github.io

This site used to publish the documentation of Data Fair. It is retired and only serves a home page pointing to:

- [docs.koumoul.com](https://docs.koumoul.com) – user guides and tutorials
- [datafair.cloud](https://datafair.cloud) – product description and architecture
- [github.com/data-fair/install](https://github.com/data-fair/install) – self-hosting and installation

Old URLs are answered by `404.html`, which shows the same links (and redirects former `/*/install/` pages to the install repository).
